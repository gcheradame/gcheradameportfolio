# Gregory Cheradame — private portfolio review

Responsive Next.js App Router project. This is a review draft, not approved for public publication.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Build with `npm run build`.

## Publication and privacy

- Do not publish without owner approval.
- No Notion API token, private Notion URL, or confidential source documents are bundled.
- `robots: noindex,nofollow` is set as a precaution, **not access control**.
- Before any Vercel deployment, enforce and verify deployment authentication on **all** environments. A random preview URL is not private.
- Content is an intentionally high-level editorial adaptation of professional Notion entries. Confirm all text before making public.
- No contact form, tracking scripts or analytics.
